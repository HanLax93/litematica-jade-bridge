# 0.1.0

Initial public release for Minecraft 26.3 (Fabric).

- Identify Litematica schematic blocks using Jade's tooltip interface.
- Display localized block names, material icons, block IDs and building materials.
- Optional build status, schematic coordinates, actual world block and block states; all four default to off.
- Add Jade Bridge Settings to the Litematica main menu.
- Support Simplified Chinese, Traditional Chinese and English.
- Include the solid charcoal-background icon with a translucent Jade-style panel.

Author: hanlax093.

Required mods: Jade 26.3.5 (Fabric), Litematica 0.29.1, MaLiLib 0.30.2 and Fabric API 0.160.3+ for Minecraft 26.3.
