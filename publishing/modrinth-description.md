# Litematica Jade Bridge

Show Litematica schematic blocks in **Jade** with localized names, item icons and building materials.

**Minecraft 26.3 · Fabric · Client-side only · Author: hanlax093**

## Features

- Identify schematic blocks using Litematica's own ray tracing.
- Display block names, icons, registry IDs and required building materials in Jade's tooltip.
- Optionally show build status, schematic position, the actual world block and block state properties.
- Detailed information is off by default to keep the tooltip compact.
- Open **Litematica Main Menu (M) → Jade Bridge Settings** to change options.
- Hide duplicate Litematica block information while Jade is enabled.
- Includes English, Simplified Chinese and Traditional Chinese translations.

## Required dependencies

Install **both [Jade](https://modrinth.com/mod/jade) and [Litematica](https://modrinth.com/mod/litematica)**.
Also install [MaLiLib](https://modrinth.com/mod/malilib) and [Fabric API](https://modrinth.com/mod/fabric-api).

Supported combination: Jade 26.3.5 Fabric, Litematica 0.29.1, MaLiLib 0.30.2, Fabric Loader 0.19.5+ and Java 25, on Minecraft 26.3.

Install the bridge JAR in the client's `mods` folder. Servers do not need this bridge.
